Every child process the engine spawns for third-party work is scoped, not just the first five. The Keychain `security` lookup, the `pass` store, `gh auth token`, `pdftotext` over a user's own PDFs, the `doctor` version probes, `pbcopy`, `xurl`, `sysctl`, the Printing Press CLIs (Digg, arXiv, Techmeme, Trustpilot), `yt-dlp`, `ffmpeg`, the Bright Data CLI, and the `agentcookie` sidecar all ran with the parent environment, so each received every API key and browser cookie the engine holds. They now get a shared allowlist of platform basics plus proxy/CA settings, carrying only the tool-specific prefixes each one needs (`GNUPGHOME`/`GPG_*` for `pass`, `SSH_*` for the ssh-wrapped `yt-dlp` lane, `HOMEBREW_*` for the brew install, `npm_config_*`/`NODE_*` for the npx install, `BRIGHTDATA_*` and `AGENTCOOKIE_*`/`BROWSER_*` for those sidecars). Children that are this project's own code — the watchlist re-spawn of `last30days.py`, the isolated `bounded_get` fetch worker — keep the environment they need.
