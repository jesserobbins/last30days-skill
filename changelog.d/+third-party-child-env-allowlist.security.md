Third-party child processes no longer inherit the user's whole environment. The npx install of the Printing Press CLIs, the Homebrew yt-dlp install, the agentcookie sidecar, the Bright Data CLI, and the openssl/security cookie-decryption helpers were all started with no `env=`, so each one received every API key, the X session cookies, cloud credentials, and SSH agent state in its environment. They now get a minimal allowlist (platform basics plus proxy/CA settings) and only the prefixes and values each tool actually needs, matching what the vendored X client and the Grok CLI child already did.
